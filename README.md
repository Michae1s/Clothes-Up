# Clothes-Up

Clothes-Up은 패션 상품 검색 및 판매처별 가격 비교를 위한 Next.js 정적 웹사이트 스타터입니다.

## 현재 포함된 기능
- 통합 검색 (브랜드·상품명·카테고리·성별)
- 성별, 카테고리, 브랜드 필터
- 최저가순 / 최고가순 / 상품명순 정렬
- 상품별 판매처 가격 비교 모달
- 모바일 반응형 화면
- 광고 슬롯 자리표시자
- 제휴 링크 연결 위치 및 고지 문구

## 중요: 현재는 데모 데이터
화면에 표시되는 12개 상품의 가격과 판매처는 예시 데이터입니다. 실제 판매처의 실시간 가격, 재고, 이미지, 구매 링크가 아닙니다. 실제 운영 전에는 각 판매처가 허용한 공식 API 또는 제휴 상품 피드를 계약·승인받아 연결해야 합니다. 허가되지 않은 자동 수집이나 이미지 무단 사용은 하지 마세요.

## 로컬에서 실행
Node.js LTS가 설치된 컴퓨터에서 프로젝트 폴더를 열고 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 무료 URL로 배포 (Cloudflare Pages)
이 프로젝트는 Next.js 정적 내보내기(`output: "export"`)를 사용합니다.

1. GitHub에서 새 저장소를 만듭니다.
2. 이 프로젝트 파일 전체를 저장소에 올립니다.
3. Cloudflare 대시보드의 Workers & Pages에서 Pages 프로젝트를 만듭니다.
4. Git 저장소를 연결합니다.
5. 빌드 설정:
   - Framework preset: `Next.js (Static HTML Export)`
   - Build command: `npx next build`
   - Build output directory: `out`
6. 배포가 끝나면 `프로젝트이름.pages.dev` 형태의 무료 주소가 생성됩니다.

공식 가이드: https://developers.cloudflare.com/pages/framework-guides/nextjs/deploy-a-static-nextjs-site/

## 나중에 유료 도메인 연결
Cloudflare Pages 프로젝트의 Custom domains에서 구매한 도메인을 연결하면 됩니다. 지금 사용하는 `.pages.dev` 주소는 계속 사용할 수 있습니다.

## 광고 및 제휴 수익 연결 순서
1. 방문자에게 제공할 독창적인 콘텐츠와 정확한 가격 데이터를 준비합니다.
2. 광고 서비스의 사이트 심사를 통과한 뒤 광고 슬롯에 승인된 스크립트를 삽입합니다.
3. 판매처/제휴 네트워크와 정식 제휴 승인을 받습니다.
4. 발급받은 추적 링크를 상품 데이터의 `affiliateUrl` 필드에 저장하고, 실제 버튼을 링크로 전환합니다.
5. 제휴 링크 근처에 경제적 이해관계가 있음을 명확하게 표시합니다.

미성년자는 서비스별 계약·정산 연령 요건을 확인하고 보호자와 함께 진행해야 합니다. Google AdSense는 만 18세 이상이 신청할 수 있고, 미성년자의 경우 보호자가 본인 Google 계정으로 신청할 수 있습니다.

## 실제 데이터 연동을 위해 필요한 다음 작업
- 상품 고유 ID / 옵션 / 사이즈 / 색상 / 배송비 / 쿠폰 적용 조건을 포함한 공통 상품 스키마
- 각 플랫폼의 공식 API 또는 승인된 제휴 피드
- 가격 갱신 시각과 출처 표시
- 같은 상품/옵션을 식별하는 매칭 로직
- 실제 가격 데이터 저장용 DB 및 주기적 갱신 작업
- 개인정보 처리방침, 이용약관, 제휴 고지, 문의 페이지

현재 정적 사이트에는 서버·DB·실제 가격 수집 기능이 포함되어 있지 않습니다.
